# Глоссарий предметной области

Справочник для разработчиков и ИИ-ассистентов. В коде используются английские идентификаторы из колонки «Код».

## Основные понятия

| Термин | Код | Что это |
|---|---|---|
| Лесосека | `CuttingSite` | Участок леса, где проведена рубка. Единица анализа. Есть площадь, контур, адрес: субъект → лесничество → участковое лесничество → квартал → выдел. |
| Подрост | `UndergrowthRecord` | Молодое поколение деревьев под пологом или на вырубке, ещё не ставшее молодняком. Главный фактор решения. |
| Жизнеспособный подрост | `viableShare` | Здоровый подрост, способный вырасти в древостой: не повреждён, не угнетён, с нормальной хвоей и вершиной. |
| Группа высоты подроста | `HeightClass` | Мелкий (до 0,5 м) — `small`, средний (0,6–1,5 м) — `medium`, крупный (> 1,5 м) — `large`. |
| Коэффициент пересчёта | `heightCoefficients` | Пересчитывает подрост в «крупный эквивалент»: мелкий × 0,5, средний × 0,8, крупный × 1,0 (демо-значения, сверить). |
| Приведённое количество | `normalizedViableCount` | Σ (количество × доля жизнеспособного × коэффициент высоты), шт/га. Считается только по целевым породам. |
| Норматив | `requiredCount` | Минимальное приведённое количество подроста для естественного лесовосстановления. Зависит от лесного района и группы пород. |
| Встречаемость | `occurrence` | Доля учётных площадок с хотя бы одним жизнеспособным подростом целевой породы. Показывает, насколько равномерно распределён подрост. |
| Учётная площадка | `SurveyPlot` | Небольшая площадка (обычно 2×2 или 10 м²), на которой при осмотре считают подрост. |
| Заключительный осмотр | `inspectionDate` | Осмотр лесосеки после окончания рубки. Даёт фактические данные о сохранённом подросте. |
| Таксационное описание | — | Характеристики выдела из лесоустройства: состав, возраст, ТЛУ, тип леса и т. д. |
| ТЛУ (тип лесорастительных условий) | `SiteConditionCode` | Код по Погребняку: буква — богатство почвы (А — боры, В — субори, С — сугрудки, D — груды), цифра — влажность (1 — сухие … 4 — сырые, 5 — болото). В коде латиница: `A2`, `B3`, `C2`. |
| Лесорастительная зона / лесной район | `ForestZoneId` / `ForestDistrict` | Районирование по Приказу № 367. Нормативы зависят от лесного района. |
| Целевые (главные) породы | `targetSpecies` | Хозяйственно ценные породы, которые должны сформировать насаждение на данном ТЛУ: сосна на А, ель на С и т. д. |
| Смена пород | `undesiredShare` | Ситуация, когда хвойный лес после рубки зарастает берёзой или осиной. Риск, который учитывает модель. |
| Формула состава | `preFellingComposition` | Запись вида `6С3Е1Б`: 6 единиц сосны, 3 ели, 1 берёзы (в сумме 10). |

## Способы лесовосстановления (ст. 62 ЛК РФ)

| Решение | Код | Цвет на карте | Когда |
|---|---|---|---|
| Естественное | `natural` | изумрудный | Жизнеспособного подроста целевых пород достаточно (≥ норматива), и он распределён равномерно. Мероприятия — сохранение подроста, при необходимости содействие. |
| Комбинированное | `combined` | янтарный | Подроста не хватает до норматива, но он есть (≥ 50 % норматива) или распределён неравномерно. Сохраняем подрост и досаживаем в «окна». |
| Искусственное | `artificial` | красный | Подроста мало (< 50 % норматива), нет целевых пород или высокий риск смены пород. Посадка или посев на всей площади. |
| Недостаточно данных | `insufficient_data` | индиго | Подрост не обследован или данные противоречивы. Нужен натурный осмотр. |

## Меры (MeasureCode)

| Код | Мера |
|---|---|
| `preserve_undergrowth` | Сохранение подроста при рубке и после неё |
| `soil_mineralization` | Минерализация поверхности почвы (содействие) |
| `fencing` | Огораживание от повреждения |
| `gap_planting` | Посадка в «окна», куртины и прогалины |
| `planting` | Посадка лесных культур на всей площади |
| `sowing` | Посев семян |
| `agrotech_care` | Агротехнические уходы за культурами |
| `thinning_softwood` | Осветление: удаление нежелательных мягколиственных пород |

## Породы (SpeciesCode)

| Код | Порода | Группа |
|---|---|---|
| `pine` | Сосна обыкновенная | хвойные |
| `spruce` | Ель | хвойные |
| `fir` | Пихта | хвойные |
| `larch` | Лиственница | хвойные |
| `cedar` | Кедр (сосна сибирская или корейская) | хвойные |
| `oak` | Дуб | твердолиственные |
| `ash` | Ясень | твердолиственные |
| `linden` | Липа | мягколиственные* |
| `birch` | Берёза | мягколиственные |
| `aspen` | Осина | мягколиственные |
| `alder` | Ольха серая | мягколиственные |

\* В лесоводстве липу относят к мягколиственным. В прототипе это не принципиально.

## Тип рубки (FellingType)

`clear` — сплошная, `selective` — выборочная, `sanitary_clear` — сплошная санитарная, `sanitary_selective` — выборочная санитарная.
После выборочных рубок лесовосстановление, как правило, не требуется: лесной покров сохраняется. Модель это учитывает.
