# Spec Delta

## Purpose

Сводная аналитика по решениям о лесовосстановлении. Превращает решения по отдельным лесосекам в план работ, потребность в посадочном материале и бюджет по стране и субъектам.

## ADDED Requirements

### Requirement: Вид «Аналитика»
При `view = 'analytics'` поверх карты SHALL открываться полноэкранная рабочая область. Карта под ней остаётся живой, затемнённой и размытой. Закрытие — вкладкой «Карта» или Esc.

#### Scenario: Открытие аналитики
- **WHEN** пользователь нажимает вкладку «Аналитика»
- **THEN** за ≈ 250 мс появляется рабочая область, карта на фоне затемняется и размывается

### Requirement: Учёт фильтров
Все графики и таблицы аналитики SHALL строиться по видимым лесосекам (фильтры стора), а в заголовке MUST показываться активные фильтры.

#### Scenario: Фильтр по субъекту
- **WHEN** в фильтре выбрана только Нижегородская область
- **THEN** все графики показывают только её, в заголовке — чип «Нижегородская область»

### Requirement: Решения по субъектам
Аналитика SHALL показывать горизонтальную накопительную диаграмму площади по четырём решениям для 20 крупнейших субъектов, сортированных по общей площади. Остальные субъекты объединяются в строку «Остальные».

#### Scenario: Наведение на сегмент
- **WHEN** курсор над сегментом «Искусственное» у Иркутской области
- **THEN** тултип показывает площадь в га, долю и число лесосек

### Requirement: Потребность в посадочном материале
Аналитика SHALL показывать потребность в сеянцах по породам с разбивкой на ОКС и ЗКС, общий итог крупным числом и подпись «для планирования питомников».

#### Scenario: Итог сеянцев
- **WHEN** открыт вид «Аналитика»
- **THEN** крупно показан итог, например «412 млн сеянцев», и столбцы по породам с двумя сегментами ОКС и ЗКС

### Requirement: Бюджет
Аналитика SHALL показывать оценочный бюджет лесовосстановления по субъектам (топ-15) с подписью «оценочно, по демо-тарифам».

#### Scenario: Бюджет субъекта
- **WHEN** пользователь наводит курсор на столбец субъекта
- **THEN** тултип показывает сумму в ₽ и площадь посадки в га

### Requirement: Распределение достаточности подроста
Аналитика SHALL показывать гистограмму коэффициента достаточности (0–3, шаг 0,1, последний бин 3+), взвешенную по площади. На ней MUST быть вертикальные линии порогов `combinedLowerRatio` и 1,0 и зоны, закрашенные цветами решений.

#### Scenario: Пороги на гистограмме
- **WHEN** открыта гистограмма
- **THEN** видны линии на 0,5 и 1,0, слева красная зона, между ними янтарная, справа изумрудная

### Requirement: Решения по годам рубки
Аналитика SHALL показывать накопительные столбцы площади по решениям для каждого года рубки.

#### Scenario: Годы
- **WHEN** открыт график по годам
- **THEN** есть столбцы 2021–2025, каждый разбит на 4 цвета решений

### Requirement: Таблица субъектов
Аналитика SHALL содержать таблицу субъектов: лесосеки, площадь, доли решений, площадь посадки, сеянцы, бюджет. Таблица сортируется кликом по заголовку. Кнопка «Экспорт CSV» MUST скачивать её содержимое.

#### Scenario: Сортировка и экспорт
- **WHEN** пользователь сортирует по «Сеянцы» по убыванию и нажимает «Экспорт CSV»
- **THEN** скачивается `regions.csv` (UTF-8 с BOM, разделитель «;») с теми же строками в том же порядке

### Requirement: Переход на карту
Клик по субъекту на любом графике или в таблице SHALL переключать вид на «Карта» и выбирать субъект с перелётом камеры.

#### Scenario: Из таблицы на карту
- **WHEN** пользователь кликает строку «Красноярский край»
- **THEN** `view = 'map'`, `selectRegion('RU-KYA', {fly: true})`
