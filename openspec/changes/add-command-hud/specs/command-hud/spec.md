# Spec Delta

## Purpose

Игровой интерфейс поверх карты в стиле RTS-стратегии: сводка по стране, управление режимами, фильтрами и слоями, навигация, горячие клавиши.

## ADDED Requirements

### Requirement: Полоса ресурсов
Вверху экрана SHALL быть полоса с логотипом и KPI по видимым (отфильтрованным) лесосекам:
- число лесосек;
- площадь;
- доли четырёх решений с цветными метками;
- потребность в сеянцах;
- оценочный бюджет.

Значения MUST анимированно пересчитываться при изменении данных.

#### Scenario: Фильтр меняет KPI
- **WHEN** пользователь выключает решение «Естественное» в фильтре
- **THEN** число лесосек и площадь в полосе пересчитываются с анимацией count-up, доля «Естественное» становится 0 %

### Requirement: Вкладки видов
В полосе ресурсов SHALL быть вкладки «Карта», «Аналитика», «Нормативы», переключающие `view` в сторе, и живые часы с датой на русском.

#### Scenario: Переключение вида
- **WHEN** пользователь нажимает «Аналитика»
- **THEN** `view = 'analytics'`, вкладка подсвечена акцентом

### Requirement: Появление HUD после интро
Панели HUD SHALL отсутствовать в фазах `loading` и `intro` и выезжать с краёв экрана в фазе `ready`. Задержки появления: 0 / 150 / 300 мс для верхней, левой и нижней частей.

#### Scenario: Старт работы
- **WHEN** фаза становится `ready`
- **THEN** верхняя полоса, левая панель и нижняя полоса последовательно выезжают с краёв

### Requirement: Режимы карты и легенда
Левая панель SHALL содержать 5 кнопок режимов карты с горячими клавишами 1–5 и легенду текущего режима из `MAP_MODES`: категориальную или градиентную с подписями.

#### Scenario: Клавиша 2
- **WHEN** пользователь нажимает «2» вне полей ввода
- **THEN** режим карты `sufficiency`, легенда показывает градиент с подписями «нет подроста», «50 % нормы», «норма», «200 %»

### Requirement: Фильтры
Левая панель SHALL позволять фильтровать лесосеки:
- по решению — переключатели с числом и площадью;
- по субъектам — мультивыбор с поиском;
- по главной целевой породе;
- по типу рубки;
- по минимальной достоверности — слайдер.

Кнопка «Сбросить» MUST возвращать фильтры по умолчанию.

#### Scenario: Поиск субъекта
- **WHEN** пользователь вводит «вол» в поиск субъектов
- **THEN** в списке остаётся «Вологодская» (поиск без учёта регистра по `nameRu`), а её выбор добавляет `RU-VLG` в `filters.regionIds`

### Requirement: Слои
Левая панель SHALL содержать переключатели слоёв из `LayerToggles` с русскими подписями: гексы, лесосеки, субъекты, подписи, рельеф, потеря лесного покрова (GFC), атмосфера, прокрутка у края.

#### Scenario: Включение GFC
- **WHEN** пользователь включает «Потеря лесного покрова (GFC)»
- **THEN** `layers.forestLoss = true`

### Requirement: Рейтинг субъектов
Левая панель SHALL показывать «Топ-10 субъектов» по площади искусственного лесовосстановления с горизонтальной полосой распределения решений. Клик MUST выбирать субъект с перелётом камеры.

#### Scenario: Клик по субъекту в рейтинге
- **WHEN** пользователь кликает «Иркутская» в рейтинге
- **THEN** `selectRegion('RU-IRK', {fly: true})`, справа открывается карточка субъекта

### Requirement: Сворачивание панелей
Левая панель SHALL сворачиваться в узкую рейку иконок по кнопке или клавише `[`. Нижний журнал MUST сворачиваться по клавише J.

#### Scenario: Свернуть левую панель
- **WHEN** пользователь нажимает `[`
- **THEN** левая панель анимированно сворачивается в рейку шириной около 56 px, и карта занимает освободившееся место

### Requirement: Индикатор камеры
В правом нижнем углу SHALL отображаться компас (поворачивается вместе с камерой; клик сбрасывает поворот на север), координаты центра, приблизительная высота камеры в км и наклон в градусах.

#### Scenario: Сброс поворота
- **WHEN** камера повёрнута на 120°, и пользователь кликает компас
- **THEN** создаётся запрос камеры с `bearing: 0`, и компас возвращается к северу

### Requirement: Горячие клавиши HUD
HUD SHALL обрабатывать свои клавиши из таблицы foundation D13:
- 1–5 — режимы карты;
- Tab / Shift+Tab — следующий / предыдущий критический объект;
- Esc — закрыть карточку, снять выбор или выйти из «Что если»;
- `[` — левая панель, J — журнал;
- ? или F1 — справка;
- \` — кинорежим.

Клавиши MUST игнорироваться, если фокус в полях ввода.

#### Scenario: Следующий критический объект
- **WHEN** пользователь нажимает Tab
- **THEN** выбирается следующая лесосека из списка «искусственное, по убыванию площади» среди видимых, и камера летит к ней

#### Scenario: Esc по шагам
- **WHEN** открыт «Что если», и пользователь нажимает Esc трижды
- **THEN** первый Esc выходит из «Что если», второй закрывает карточку лесосеки, третий снимает выбор субъекта

### Requirement: Справка по клавишам
По ? или F1 SHALL открываться оверлей со всеми горячими клавишами приложения, сгруппированными: «Камера», «Карта», «Интерфейс».

#### Scenario: Открытие справки
- **WHEN** пользователь нажимает ?
- **THEN** появляется оверлей с клавишами, закрывается по Esc или клику вне его

### Requirement: Кинорежим
Клавиша \` SHALL скрывать весь HUD, кроме бейджа демо-данных, для презентации карты. Повторное нажатие MUST возвращать HUD.

#### Scenario: Скрыть HUD
- **WHEN** пользователь нажимает \`
- **THEN** все панели HUD плавно исчезают, карта остаётся управляемой
