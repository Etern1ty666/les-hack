# Design

## Context

Карта предоставляет `registerLayerProvider(id, provider)` (`add-strategic-map` D11). Провайдер получает `zoom`, `time`, `map` и снимок стора и возвращает слои deck.gl. Учётные площадки возвращает `getSurveyPlots(site)` (dataset D4), смещения — в метрах от центроида.

## Goals / Non-Goals

**Goals:** наглядность решения, красота уровня стратегий, укладка в бюджет инстансов.
**Non-Goals:**
- реальный рельеф: земля плоская, 3D-terrain выключен (см. map Non-Goals);
- реальные деревья по снимкам;
- физически точные размеры: используется осознанное увеличение.

## Decisions

### D1. Структура `src/map/site3d/`

```
index.ts            # registerLayerProvider('site3d', provider) при импорте модуля; импортируется из src/main.tsx
provider.ts         # собирает слои при выбранной лесосеке и zoom >= 12
scene.ts            # buildSiteScene(site, decision, plots): { undergrowth, forestRing, plots, plan } — мемоизация по (site, decision)
geometry.ts         # меши: конус кроны и цилиндр ствола (@luma.gl/engine ConeGeometry / CylinderGeometry), low-poly 6–8 граней
placement.ts        # детерминированное размещение (seed из site.id), point-in-polygon в локальных метрах
planting.ts         # ряды плана посадки
Site3dPanel.tsx     # мини-панель: «План посадки», «Облёт», легенда, пометка о масштабе (рендерится через портал в правый нижний угол карты)
orbit.ts            # облёт: rAF, bearing += 6°/с, стоп на map 'movestart' с originalEvent
```

`src/main.tsx` — файл foundation; в него добавляется одна строка `import './map/site3d'`. Это согласованное изменение.

### D2. Слои

| Слой | Тип | Детали |
|---|---|---|
| site3d-plots | ScatterplotLayer | радиус 1,6 м (визуально), заливка: мята альфа 160 или серый альфа 80, pickable |
| site3d-undergrowth-crowns | SimpleMeshLayer (cone) | `getPosition` [lon, lat, h_trunk], `getScale` [r, r, h_crown]·k, `getColor` = SPECIES.rgb |
| site3d-undergrowth-trunks | SimpleMeshLayer (cylinder) | тонкий ствол `#5B4636` |
| site3d-forest-crowns | SimpleMeshLayer (cone) | высота 18–26 м (без увеличения), цвет хвойных темнее на 25 %, примесь берёзы 20 % |
| site3d-forest-trunks | SimpleMeshLayer (cylinder) | — |
| site3d-plan | SimpleMeshLayer (cone, маленький) | альфа 110, цвет породы, `getScale` анимируется по времени появления ряда |

Освещение — `LightingEffect`: ambient 0,5 и directional с северо-запада, высота 45°. Если `LightingEffect` конфликтует с interleaved-режимом карты, используется `material` слоёв без отдельного эффекта.

### D3. Размеры и увеличение

- Высоты подроста (м): small 0,3–0,5; medium 0,6–1,5; large 1,6–3,0. Визуальный множитель `k = 4` (константа `UNDERGROWTH_VISUAL_SCALE`).
- Радиус кроны = 0,35 × высоты. Ствол — 25 % высоты.

### D4. Размещение подроста (`placement.ts`)

- Локальная система: метры от центроида (x — восток, y — север). Перевод в lon/lat: `dx / (111320 × cos(lat))`, `dy / 110540`.
- Целевое число деревьев = `Σ count × viable × areaHa`, ограниченное бюджетом 6 000. Коэффициент прореживания `thin = budget / target`, если `target > budget`.
- Деревья группируются вокруг площадок с `viableTargetCount > 0`: нормальное распределение σ = 5 м от центра площадки. Доля целевых и нецелевых пород соответствует записям подроста. Нецелевые (берёза, осина) допускаются и у пустых площадок: «пустые» означает без жизнеспособных целевых.
- Отбраковка точек вне контура.
- PRNG — `mulberry32(hash(site.id))`. Для черновика «Что если?» seed тот же, поэтому увеличение подроста добавляет деревья, а не перетасовывает их.

### D5. Окружающий лес

Полоса 6–40 м снаружи контура. Плотность — 1 дерево на 30 м², не больше 4 000. Состав по формуле состава до рубки: доли пород из `preFellingComposition`.

### D6. План посадки (`planting.ts`)

- Направление рядов — вдоль самой длинной стороны контура.
- Межрядье `rowSpacing = 3 м`, шаг в ряду = `10000 / (density × rowSpacing)`.
- Породы в ряду чередуются по составу. Например, 7С3Е: цикл из 10 мест — 7 сосен и 3 ели, перемешанные детерминированно.
- Для `combined` исключаются точки ближе 6 м к любому дереву целевого подроста.
- Ограничение 2 000 инстансов: если точек больше, рисуются ряды через один с пометкой «показан каждый 2-й ряд».
- Анимация: ряд i появляется в `t0 + i × 120 мс`, сеянец масштабируется 0 → 1 за 300 мс (ease-out-back).

### D7. Облёт

Пока облёт включён, rAF вызывает `map.setBearing(bearing + 6·dt)` и держит центр на центроиде. Остановка — по событию `movestart` с `originalEvent` (пользовательский ввод) или по нажатию любой клавиши камеры из foundation D13.

## Risks / Trade-offs

- [SimpleMeshLayer в interleaved-режиме на globe] → при зуме ≥ 12,5 MapLibre почти в mercator. Если всё же есть артефакты, 3D-вид включается с зума 13,5 (константа).
- [Производительность на слабых ноутбуках] → бюджеты инстансов в константах; при FPS < 30 (замер 2 с) бюджеты уменьшаются вдвое автоматически.
- [Увеличение высот вводит в заблуждение] → обязательная пометка в легенде (спецификация «Честный масштаб»).
