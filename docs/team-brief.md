# ПОДРОСТ — бриф для команды

## Что делаем

Хакатон Рослесхоза, **Трек №4, задача 3** — «Поддержка принятия решений о необходимости проведения мероприятий по лесовосстановлению».

По данным о подросте после рубки система решает, нужно ли лесовосстановление и каким способом:
- **естественное** — подроста хватает;
- **комбинированное** — подроста не хватает, досаживаем;
- **искусственное** — подроста нет или он неподходящий, сажаем всё.

Для каждого решения система объясняет «почему» (со ссылками на нормативы) и предлагает технологию: что сажать, сколько, когда и за сколько.

Подача — **3D-глобус в стиле стратегии с видом сверху**: вся Россия в лесосеках, зоны подсвечены по решению, интерфейс как в RTS.

## Как начать (15 минут)

1. Клонировать репозиторий и запустить проект.

   ```bash
   git clone https://github.com/Etern1ty666/les-hack.git
   ```

   ```bash
   cd les-hack
   ```

   ```bash
   npm ci
   ```

   ```bash
   npm run dev
   ```

   Откроется http://localhost:5173.
2. Поставить OpenSpec CLI (нужен ИИ-ассистенту):

   ```bash
   npm install -g @fission-ai/openspec@1.14.3
   ```

3. Прочитать `AGENTS.md` (5 минут) и свою папку change в `openspec/changes/<change>/`: `proposal.md` → `specs/` → `design.md` → `tasks.md`.
4. Создать ветку `feat/<change>`.
5. Запустить реализацию в ассистенте:
   - **Claude Code:** `/opsx:apply <change>`
   - **Cursor:** `/opsx-apply <change>`
   - **Codex:** `$openspec-apply-change <change>`
   - **другие:** «Реализуй OpenSpec change `<change>`: прочитай AGENTS.md, затем `openspec instructions apply --change <change>` и иди по tasks.md»

Ассистент идёт по `tasks.md` и отмечает чекбоксы. Если что-то непонятно, он остановится и спросит, и тогда решаем в чате.

## Правила

- **Чужие папки не трогать.** Если нужно поменять общий контракт (`src/domain/types.ts`, хранилище состояния `src/state/store.ts`), сделайте отдельный маленький PR и напишите в чат.
- **Перед PR:** `npm run typecheck && npm test`. Для визуальных задач — скриншот или GIF в PR.
- **Весь текст интерфейса на русском.** Числа форматировать через `src/domain/format.ts`, цвета брать из токенов.
- **Никаких ключей и секретов.** Нормативы демонстрационные, бейдж «Демо-данные» не убирать.
- **Горячие клавиши** распределены между потоками: таблица D13 в `openspec/changes/setup-app-foundation/design.md`.

## Грабли, на которые уже наступили

- **MapLibre только 5.24, не 6.** Шестая версия несовместима с deck.gl 9.4 (убрали `map.transform`). Не обновлять.
- **Плоские слои deck.gl** (точки, линии, контуры, кольца) на глобусе обязательно создавать с `parameters: { depthCompare: 'always', depthWriteEnabled: false }`. Иначе при наклоне камеры их закрывает поверхность глобуса. Подробности — в Decision log, `openspec/changes/add-strategic-map/design.md`.
- **После смены зависимостей** Vite может отдавать старую сборку. Тогда остановить `npm run dev`, удалить `node_modules/.vite` и запустить снова.
- **Скрытая вкладка браузера** не рисует карту: `requestAnimationFrame` на паузе. Проверять в видимом окне.

## Отладка из консоли браузера (только `npm run dev`)

- `useAppStore.getState()` — всё состояние. Например, `useAppStore.getState().selectRegion('RU-IRK')` или `.setMapMode('sufficiency')`.
- `__podrostMap` — экземпляр MapLibre: `__podrostMap.jumpTo({center: [44.9, 56.7], zoom: 8, pitch: 45})`.
- `__podrostDeck` — оверлей deck.gl.

## После мержа

- `/opsx:archive <change>` переносит спеки в `openspec/specs/`.
- В `main` всё деплоится само. Проверяйте демо по ссылке выше.

## Что важно не забыть к защите

**Нормативы в конфиге демонстрационные.** Кто-то один должен сверить их с Правилами лесовосстановления (Приказ Минприроды № 1024) для пилотной Нижегородской области. Поправить достаточно `src/engine/defaultNorms.ts`, код менять не нужно. Подробности — в [docs/task.md](task.md).
