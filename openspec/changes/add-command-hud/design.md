# Design

## Context

Примитивы (`src/ui`), токены, селекторы, стор и распределение клавиш заданы в `setup-app-foundation/design.md` (D10, D11, D13, D14, D15). Раскладка и стиль — в `docs/visual-direction.md` (раздел «Раскладка экрана»). HUD читает стор и вызывает экшены. Карту напрямую не трогает: камера управляется только через `requestCamera`, `selectSite` и `selectRegion`.

## Goals / Non-Goals

**Goals:** игровой, но читаемый интерфейс; понятное объяснение решения; «живость» через журнал и анимации; ноль покадровых ререндеров.
**Non-Goals:**
- графики и редактор нормативов — change `add-analytics-workspace`;
- печатная форма заключения — тоже там; в HUD только JSON;
- мобильная вёрстка: минимум 1280×720.

## Decisions

### D1. Структура `src/hud/`

```
index.tsx                 # Hud: монтирует зоны, если phase === 'ready' && !ui.hudHidden
TopBar/                   # Brand, KpiStrip, ViewTabs, Clock
LeftPanel/                # MapModeSwitcher + Legend, Filters, Layers, TopRegions, CollapsedRail
Dossier/                  # SiteDossier, RegionDossier, sections/*, WhatIfEditor
Feed/                     # FeedPanel, FeedItem, simulator.ts
CameraReadout/            # Compass, Coordinates
HotkeysHelp/              # оверлей справки
hotkeys.ts                # useHudHotkeys() по таблице D13
critical.ts               # список критических объектов для Tab
```

### D2. Зоны и раскладка

- Абсолютное позиционирование в контейнере `.hud` с `pointer-events: none`. У самих панелей `pointer-events: auto`, поэтому клики по пустым местам доходят до карты.
- Верхняя полоса: высота `--topbar-h`, на всю ширину, градиент сверху вниз от `--panel` к прозрачному, без рамки снизу.
- Левая панель: `top: calc(var(--topbar-h) + var(--gap))`, `left: var(--gap)`, ширина `--left-w`, высота до нижней полосы, прокрутка внутри.
- Карточка: справа, ширина `--right-w`, высота как у левой панели.
- Нижняя полоса: высота `--bottom-h`. Слева — место под миникарту (её рисует поток map) шириной `--minimap-w`, в центре — журнал, справа — CameraReadout (около 240 px).
- Анимации входа и выхода — через `motion` (`AnimatePresence`), длительности из visual-direction.

### D3. Полоса ресурсов (`KpiStrip`)

Источник — `selectKpis`. Порядок:
1. «ЛЕСОСЕК» — `fmtInt`;
2. «ПЛОЩАДЬ» — `fmtCompact` + «га»;
3. четыре доли — точка цвета решения и `fmtPct` по площади; тултип с числом и площадью;
4. «СЕЯНЦЕВ» — `fmtCompact` + «шт»;
5. «БЮДЖЕТ ≈» — `fmtRub`; тултип «Оценка по демо-тарифам, не норматив».

Значения — через `AnimatedNumber`. Между группами — вертикальные разделители с градиентом.

Логотип: ромб-иконка (SVG, `--accent`) и «ПОДРОСТ» шрифтом Unbounded 800, с лёгким свечением. Под ним мелкий подзаголовок «ЛЕСОВОССТАНОВЛЕНИЕ · КОМАНДНЫЙ ЦЕНТР». Название бренда берётся из `src/shell/brand.ts`.

Часы обновляются раз в секунду в изолированном компоненте, который не вызывает ререндер родителя. Формат: «23 окт 2026 · 14:05:31».

### D4. Левая панель

- **Режимы**: 5 кнопок-плиток с иконкой, подписью и `Kbd` с цифрой. Под ними легенда: для категориальных — список «цвет + подпись», для непрерывных — градиентная полоса и подписи стопов.
- **Фильтры**:
  - решения — 4 `Chip` в toggle-режиме с числом и площадью; хотя бы одно решение всегда включено;
  - субъекты — поле поиска (по `nameRu`, без учёта регистра и буквы ё) и список с чекбоксами; выбранные показываются чипами сверху;
  - порода — чипы пород из `SPECIES`, только хвойные и твердолиственные, то есть целевые;
  - тип рубки — 4 чипа;
  - достоверность — `Slider` 0–100 %.
- **Слои**: `Toggle` для каждого ключа `LayerToggles` с русскими подписями.
- **Топ-10**: `selectRegionStats`, сортировка по `byKindArea.artificial`, строка = название, площадь искусственного и мини-полоса из 4 сегментов.
- **Свёрнутое состояние**: рейка 56 px с иконками разделов; клик по иконке разворачивает панель на этом разделе.

### D5. Карточка лесосеки (`SiteDossier`)

Источник: `sitesById[selectedSiteId]` и `selectEffectiveDecision`. Секции по спецификации `site-dossier`, сверху вниз:
1. шапка;
2. решение;
3. метрики;
4. подрост;
5. почему так;
6. рекомендация;
7. факторы прогноза;
8. действия.

Секции 3–7 — сворачиваемые, по умолчанию раскрыты 2, 3, 5 и 6.

- Кольцо достоверности — SVG-дуга, цвет от `--nodata` (низкая) до `--accent` (высокая).
- `Meter` для достаточности: шкала 0–200 %, отметки на 50 % и 100 %, цвет по `colorForModeValue('sufficiency', ratio)`.
- Таблица подроста: строки сгруппированы по породе; вклад = `count × viable × coef`, считается тут же для отображения и не дублирует логику решения.
- Иконки исходов трассировки: `pass` — галочка `--natural`, `fail` — крест `--artificial`, `warn` — треугольник `--combined`, `info` — точка `--text-1`.

### D6. «Что если?» (`WhatIfEditor`)

- Включение — `startWhatIf(siteId)`. Каждое изменение — `updateWhatIf(draft)`, который пересчитывает `whatIf.result` в сторе.
- Слайдеры обновляют черновик с `requestAnimationFrame`-троттлингом: одно обновление на кадр.
- Рядом с бейджем — «было: X» и стрелка, если `kind` изменился; дельта коэффициента достаточности в п. п.
- Кнопки «Сбросить» (`startWhatIf` заново) и «Выйти» (`endWhatIf`).
- Пока черновик активен, у карточки акцентная пунктирная рамка и метка «ЧЕРНОВИК».

### D7. Журнал (`Feed`)

- `simulator.ts`: таймер `setTimeout` со случайной задержкой 3,5–7 с. Выбор — взвешенная выборка из `selectVisibleSiteIds`: вес 2 для `combined` и `artificial`, 1 для остальных.
- Событие `pushFeed`:
  - `type`: `alert`, если `artificial` и `areaHa > 25`, иначе `inspection`;
  - `location = site.centroid`, `decision`, `siteId`, `regionId`.
- Пауза: `document.visibilityState === 'hidden'` или кнопка «Пауза». Состояние паузы — локальное, в компоненте.
- Список: `AnimatePresence` с `layout`-анимацией. Новая запись 1,2 с подсвечивается фоном `--accent-dim`.

### D8. CameraReadout

- Компас: SVG-роза с буквой «С», `rotate(-bearing)`.
- Координаты — `fmtLonLat(camera.center)`.
- Высота: `altitudeKm ≈ (viewportHeightPx / 2) × (40075 × cos(lat) / (512 × 2^zoom)) / tan(fov / 2)` при `fov = 36.87°`, округление до 2 значащих цифр. Для зума < 3 — «орбита».
- Наклон — «35°».

### D9. Горячие клавиши (`hotkeys.ts`)

Один `keydown`-обработчик на `window`, таблица из foundation D13 (только клавиши hud). Каскад Esc:
1. открыта справка → закрыть;
2. `whatIf` → `endWhatIf`;
3. `selectedSiteId` → `selectSite(null)`;
4. `selectedRegionId` → `selectRegion(null)`.

Tab по `critical.ts`: видимые `artificial`, сортировка по `areaHa` по убыванию, затем по `confidence` по убыванию. Индекс хранится в ref и сбрасывается при смене фильтров.

## Risks / Trade-offs

- [Перегруз экрана] → по умолчанию раскрыты только ключевые секции; кинорежим одной клавишей.
- [Частые ререндеры из-за `camera` в сторе] → CameraReadout подписан только на `camera`, остальные компоненты используют узкие селекторы zustand (`useAppStore(s => s.x)` и shallow).
- [Данные заглушки до мержа engine] → карточка устойчива к пустым `composition` и `successFactors`.
