# Proposal

## Why

Это ядро решения задачи хакатона: по данным о подросте определить, нужно ли лесовосстановление, каким способом и с какими параметрами. Решение должно быть **прозрачным**: жюри и лесничий видят каждый шаг и ссылку на норму. Оно должно быть **быстрым**: 60 000 лесосек пересчитываются меньше чем за 0,3 с, поэтому нормативы можно править на лету.

## What Changes

- Экспертный движок правил: целевые породы по ТЛУ и лесному району → приведённое количество подроста → сравнение с нормативом → встречаемость → риск смены пород → решение.
- Технологическая карта для комбинированного и искусственного лесовосстановления:
  - состав культур, густота, посадочный материал;
  - обработка почвы, сезон, уходы;
  - объём сеянцев, оценочная стоимость, срок перевода в покрытые лесом земли.
- Достоверность решения: полнота данных, свежесть осмотра, близость к порогам.
- Прогноз успешности формирования целевого насаждения: логистическая модель с объяснением вклада факторов. Интерфейс позволяет заменить её обученной моделью.
- Сравнение двух наборов решений (`diffDecisions`) для редактора нормативов.
- Набор «золотых» тестов и бенчмарк производительности.

## Capabilities

### New Capabilities
- `reforestation-decision`: определение необходимости и способа лесовосстановления по подросту и нормативам, трассировка правил, достоверность, сравнение решений.
- `reforestation-recommendation`: технологические параметры лесовосстановления и прогноз успешности.

- Заменяет заглушку `src/engine/index.ts`. Сигнатуры из `setup-app-foundation/design.md` D7 не меняются.
