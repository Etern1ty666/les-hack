# Spec Delta

## Purpose

Публикация прототипа по публичному URL, чтобы жюри и команда всегда видели актуальную версию без локальной сборки.

## ADDED Requirements

### Requirement: Автоматическая публикация
Каждый пуш в ветку `main` SHALL собирать приложение и публиковать его на GitHub Pages. Сборка MUST падать при ошибках типов.

#### Scenario: Пуш в main
- **WHEN** в `main` попадает коммит, проходящий `npm run typecheck` и `npm run build`
- **THEN** через несколько минут новая версия доступна по адресу `https://<owner>.github.io/<repo>/`

#### Scenario: Ошибка типов
- **WHEN** в `main` попадает коммит с ошибкой TypeScript
- **THEN** workflow завершается с ошибкой, и опубликованная версия не меняется

### Requirement: Работа под подпутём
Собранное приложение SHALL корректно загружать все ресурсы (JS, шрифты, данные из `public/data`) под подпутём репозитория GitHub Pages.

#### Scenario: Загрузка данных под подпутём
- **WHEN** приложение открыто по адресу `https://<owner>.github.io/<repo>/`
- **THEN** файлы из `public/data` загружаются с учётом базового пути, без 404

### Requirement: Без секретов
Сборка и рантайм SHALL обходиться без API-ключей и секретов: все внешние источники должны быть публичными и бесключевыми.

#### Scenario: Чистый клон
- **WHEN** разработчик клонирует репозиторий и выполняет `npm ci && npm run dev`
- **THEN** приложение запускается без файлов `.env` и без ключей
