# Сценарий демо для жюри (≈ 4 минуты)

Каждый шаг — функция, которая **обязана** работать на защите. Сверяйтесь с этим списком при приёмке.

| # | Что делаем | Что видит жюри | Change |
|---|---|---|---|
| 1 | Открываем приложение | Экран загрузки: «Загрузка данных…», затем счётчик «Проанализировано 60 000 лесосек» | foundation, engine, dataset |
| 2 | «Начать» | Вращающийся глобус в космосе. Камера пролетает к России, гексы вырастают волной. Верхняя полоса считает KPI | map, hud |
| 3 | Клавиши `1`→`2`→`3` | Режимы карты: «Решение», «Достаточность подроста», «Порода». Страна перекрашивается | map |
| 4 | WASD / Q-E / колесо | Камера как в RTS: панорама, поворот, наклон, зум | map |
| 5 | Клик по региону в «Топ-10» (Иркутская) | Перелёт, подсветка провинции, карточка региона | hud, map |
| 6 | В журнале приходит осмотр «Нижегородская обл. … Комбинированное», клик | Перелёт к лесосеке, пинг, RTS-кольцо, карточка лесосеки | hud, map |
| 7 | Карточка: «Почему?» | Шаги правил с расчётом: «Приведённое 1 840 шт/га < норматива 2 500 шт/га (74 %)», встречаемость 70 % ≥ 65 %, ссылка на Правила лесовосстановления с меткой «не сверено» | engine, hud |
| 8 | Рекомендация | Состав культур 7С3Е, густота 3 350 шт/га, сеянцы ОКС, борозды, весна, уходы 3 года, посадка на 3,0 га из 10, сеянцев 10 050 шт, ≈ 180 тыс. ₽. Это расчёт из золотого теста G1 движка | engine, hud |
| 9 | «Что если?»: двигаем слайдер подроста ели вверх | Решение в реальном времени меняется на «Естественное», цвет на карте тоже | hud, engine |
| 10 | Зум в лесосеку (3D) | Низкополигональные деревья подроста, учётные площадки, призрачные ряды будущей посадки | site3d |
| 11 | Вкладка «Нормативы»: встречаемость 65 % → 75 % | Россия перекрашивается, плашка «Изменилось 3 412 решений» | analytics |
| 12 | Вкладка «Аналитика» | Потребность в сеянцах по породам (для питомников), бюджет, решения по регионам | analytics |
| 13 | Перетаскиваем CSV с «реальным» осмотром | Новая лесосека сразу оценена и показана на карте | analytics |

## Ключевые фразы

- «Модель прозрачна: каждое решение — цепочка проверок со ссылкой на норму».
- «Нормативы — это конфиг. Поменяли норму — страна пересчиталась за 0,2 секунды».
- «Помимо ответа "надо или нет", система отвечает на вопросы "что сажать, сколько, когда и за сколько"».
- «Агрегаты сразу дают потребность в посадочном материале для питомников на следующий сезон».
